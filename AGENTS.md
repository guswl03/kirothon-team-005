# PRD-first product development

When building a product, read the supplied PRD (`PRD.md` by default) and use `.kiro/skills/prd-to-repo/SKILL.md`.

Implement the requested product in this repository. Choose a suitable stack, keep the original PRD intact unless asked to edit it, and provide setup and run instructions in the product README. Include deployment configuration and instructions when the PRD or user requests deployment.

Summarize what was built and any remaining work.
