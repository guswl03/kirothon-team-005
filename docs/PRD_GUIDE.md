# PRD 작성 가이드

제품 요구사항을 `PRD.md`에 자유로운 형식으로 작성하세요. 다음 항목을 넣으면 원하는 결과를 전달하는 데 도움이 됩니다.

| 항목 | 예시 |
| --- | --- |
| 제품 목적 | 해결할 문제와 대상 사용자 |
| 주요 기능 | 사용자 시나리오와 필요한 기능 |
| 범위와 우선순위 | 먼저 만들 기능과 제외할 기능 |
| 기술 선택 | 원하는 언어, 프레임워크, 데이터베이스 |
| 외부 연동 | 연동할 서비스와 사용 가능한 정보 |
| 실행 및 배포 | 실행 환경, 배포 대상, 필요한 설정 |
| 기타 요구사항 | 제품에 필요한 성능, 접근 권한, 테스트 등 |

명시되지 않은 기술과 구성은 제품에 맞게 선택합니다.
