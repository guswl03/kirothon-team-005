# Kiro Crew 연동

Kiro Crew를 사용한다면 이 저장소를 작업 디렉터리로 선택하고 `PRD.md`를 준비하세요. Crew에 다음과 같이 요청하면 됩니다.

```text
PRD.md를 읽고 .kiro/skills/prd-to-repo/SKILL.md를 따라 제품을 구현해줘.
실행에 필요한 설정과 README를 만들고, 요청한 배포 설정도 준비해줘.
```

Crew의 기능과 설정은 설치 환경에 따라 달라질 수 있습니다. 자세한 내용은 [Kiro Crew 문서](https://kiro.dev/docs/crew/)를 참고하세요.
