# 선택 감지 호환성

시연 대상 프로그램에서 자동 선택 감지가 되는지 기록하는 표입니다. 담당: A.

## 측정 방법

1. `npm run compat`을 실행합니다. 3초의 대기 시간이 있습니다(`npm run compat -- 5`처럼 초를 바꿀 수 있습니다).
2. 대기 시간 안에 **측정할 프로그램으로 이동해 텍스트를 선택**합니다.
3. 출력된 표 한 줄을 아래 표에 붙여 넣고, "지연(초)"은 앱을 켠 상태에서 선택부터 결과 창이 뜰 때까지 직접 잰 값을 적습니다.

측정 도구는 선택된 텍스트의 내용이나 창 제목을 출력하지 않고 길이와 프로세스 이름만 출력합니다.

## 결과

| 프로그램 | 버전 | 감지 | 지연(초) | 비고 |
|---|---|---|---|---|
| Notepad | 11.2609.11.0 | 지원 | 약 0.9 | 선택 5자 읽음, class=RichEditD2DPT; 드래그 |
| chrome | 157.0.8103.52 | 지원 | 약 1.2 | 선택 4자 읽음, class=; 드래그 |
| WINWORD | 16.0.17328.20206 | 지원 | 약 0.7 | 선택 32자 읽음, class=_WwG; 키보드 선택, 드래그 미검증 |
| KakaoTalk | 26.9.2.5342 | 지원 | 약 1.1 | 선택 12자 읽음, class=RICHEDIT50W; 채팅 입력란 키보드 선택, 드래그 미검증 |

측정: 2026-11-14, 오프라인 간이 모드. 지연은 선택 완료 후 숨겨진 결과 창이 표시될 때까지의 단일 측정값이며, 약 0.1초 간격으로 창 표시를 확인했다. 검색과 문장 생성이 완료되기까지의 시간은 포함하지 않는다.

C 전달용(미전달): 메모장과 크롬은 드래그로 시연한다. 워드와 카카오톡은 드래그를 재확인하기 전까지 복사(`Ctrl+C`) 후 `Ctrl+Alt+Space` 또는 붙여넣기를 사용한다. 미지원 판정은 없었으며, 연락 대상이 정해지지 않아 직접 알리지는 못했다.

## 판정 기준과 대응

- **지원**: 자동 분석으로 시연합니다.
- **미지원**: 앱이 한 번 안내를 띄웁니다. 시연에서는 텍스트를 복사(`Ctrl+C`)한 뒤 `Ctrl+Alt+Space`를 누르거나 붙여넣기를 씁니다.
- **지원(선택 없음)**: 선택 후 다시 측정합니다.
- 크롬/엣지가 미지원이면 `chrome://accessibility` 또는 `edge://accessibility`에서 접근성을 켠 뒤 다시 측정합니다.
