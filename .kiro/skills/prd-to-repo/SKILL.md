# PRD to product

1. Read the supplied PRD, using `PRD.md` by default.
2. Choose a suitable stack and implement the requested product in this repository.
3. Add the configuration and instructions needed to install and run it. Replace the factory README with the product's README.
4. When the PRD or user requests deployment, add the deployment configuration and instructions and carry out the requested deployment when the environment permits.
5. Summarize what was built and any remaining work.

Keep the source PRD intact unless the user asks to edit it.
