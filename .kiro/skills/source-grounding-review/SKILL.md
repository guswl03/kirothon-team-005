# 출처 근거 검토

앱의 원칙: 사실은 검색된 출처에 연결된 것만 사실로 보여 준다. 근거가 없으면 일반 표현(`general`)으로 낮추고 지어내지 않는다.

## 절차
1. 대상 주제로 MCP `cheatsheet-dev`의 `wiki_search`를 호출해 출처(`S1`~`S3`)와 본문을 받는다.
2. 검토할 모델 응답 JSON을 `verify_result`에 `sources`와 함께 넣는다. `demotedStatements`와 각 항목의 `basis`, `sourceIds`를 본다.
3. 강등이 이상하면 해당 문장과 출처 본문을 `support_score`에 넣어 점수를 본다. 기준은 `SUPPORT_MIN`(0.3)이다.
4. 판단한다.
   - 맞게 강등됨: 문장이 출처에 없는 내용이다. 프롬프트가 근거 없는 사실을 만들지 않게 할 방법을 찾는다.
   - 잘못 강등됨(근거가 있는데 점수가 낮음): 의역이 심한 경우다. 기준을 바로 낮추지 말고, 같은 패턴의 사례 3개 이상을 모아 테스트로 남긴 뒤 결정한다.
   - 잘못 통과됨(근거가 없는데 점수가 높음): 출처의 단어만 섞은 문장이다. `test/ai/schema.test.js`에 실패 사례로 추가한다.
5. 바꾼 경우 `node --test "test/ai/*.test.js"`와 오프라인 회귀 테스트("오프라인 간이 모드의 인용 문장은 검증에서 강등되지 않는다")가 통과하는지 확인한다.
